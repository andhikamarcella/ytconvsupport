Pertanyaan umum

Berapa lama tiket diperiksa?

Waktu penanganan bergantung pada jenis masalah dan antrean. Gunakan halaman status untuk melihat pembaruan terbaru dari tim support.

Apakah ID tiket harus disimpan?

Ya. ID tiket adalah cara utama untuk membuka halaman status. Jangan membagikannya di tempat publik.

Data apa yang tidak boleh dikirim?

Jangan pernah mengirim password, token login, cookies.txt, API key, private key, nomor kartu, atau informasi rahasia lain melalui formulir.
